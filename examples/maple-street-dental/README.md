# Maple Street Dental — SAMPLE

SAMPLE — Maple Street Dental is a fictional business. This folder is a
complete, filled-in rollout used to show what the Pack looks like in
practice and to exercise the checker. Any resemblance to a real clinic is
a coincidence of good naming.

Run it:

```bash
rollout-pack check examples/maple-street-dental
rollout-pack map examples/maple-street-dental
```
