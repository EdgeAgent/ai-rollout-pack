# The Rollout Checklist

The whole rollout on one page: day one, week one, first month. The order
matters more than the speed. Governance comes before go-live, and scope is
earned, never assumed.

## Day 1 — set up one lane

- [ ] Pick ONE lane to pilot. One lane, one job, one named human owner.
- [ ] Write the lane's one-pager. If the job does not fit on one page,
      the lane is too big — split it.
- [ ] Start the memory folder: the facts the lane depends on, written
      down.
- [ ] Sign the governance sheet: owners, approval gates, the
      do-not-contact (scrub) rule, the kill switch.
- [ ] Pull the kill switch once, on purpose, to prove it works.
- [ ] Run the checker (`rollout-pack check`) — all rules PASS before
      anything goes live.

## Week 1 — pilot, human in the loop

- [ ] Every send, publish, and payment is drafted by the AI employee and
      approved by a human. Every one. Trust is earned in this week or
      not at all.
- [ ] Log each task: what it was, roughly how long a human would have
      taken, errors caught. This log is the pilot's report card.
- [ ] Write every correction into memory the same day it happens.
- [ ] Friday review: the lane owner reads the log and the corrections,
      then writes down — on the one-pager — what the lane may do next
      week that it could not do this week, if anything.

## First month — earn scope, measure honestly

- [ ] Weekly checker runs after any change to a one-pager or the
      governance sheet.
- [ ] Confirm scrub discipline: zero outreach to anyone on the
      do-not-contact list, all month.
- [ ] Month review with numbers: hours the lane returned versus hours it
      was meant to return. Keep, shrink, or stop the lane based on the
      log — not on how impressive the demo felt.
- [ ] If the lane earned it, consider a second lane. It starts at its own
      day one: its own one-pager, owner, and governance review.

## The rule underneath all of it

Scope is a reward for a clean log, not a plan made in advance. An AI
employee that does one small job provably well is worth more than one
that does ten jobs nobody has checked.
